## Tumblr templates

Velvet Midnight renders the supplied Charlie Tumblr theme and About page in the portfolio preview. The preview serves the supplied portrait locally and fills Tumblr variables with sample posts. Install the main file in Tumblr’s custom HTML editor and the About file as a Custom Layout page at /about. The Meadow Scrapbook file also uses the custom HTML editor.

The [Beatrice portrait referenced in both supplied files](https://i.postimg.cc/TwWt8C28/5.png) is user-supplied artwork. The original artist and commercial reuse license are unverified. The image is used in the local preview at the user’s request. The Tumblr installation files retain the original image reference.

## Toyhouse templates

The downloads use Bootstrap 4 classes and inline styles, with native Toyhouse tab attributes. The preview artwork is separate. Each image URL identifies a slot for an image you can host and use.
